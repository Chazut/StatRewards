# StatRewards 1.3.0

## Features

- Reward parcels now mix categories and avoid duplicate items while your reward pool has enough variety. Varied parcels are on by default.
- Edit each milestone's reward pool, trader and payout frequency in the new ORBIT-themed editor in SPT's web menu. Preview a sample parcel before saving.

## Upgrading

Keep your existing `config/mod_config.jsonc` when extracting the ZIP. Saved settings take effect after a server restart.
